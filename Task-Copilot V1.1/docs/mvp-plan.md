# MVP 状态与后续

截至 2026-10-02，以下能力已实现：基础窗口与托盘、SQLite 迁移、任务、项目与子任务、学期课表与单双周/临时调课、Dashboard、7/30 天 DDL、自由专注时长、Analytics 和独立后台课程/任务提醒。番茄钟按用户要求不实现。
